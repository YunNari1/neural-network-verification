# Assignment 4: alpha-beta-CROWN Neural Network Verification

Applies [α,β-Crown](https://github.com/Verified-Intelligence/alpha-beta-CROWN) to verify
L∞-robustness of a small MNIST MLP (784→64→32→10).  
The same model used in Assignment 3 (Marabou) is reused to enable a direct comparison.

---

## Setup

### 1. Clone alpha-beta-CROWN

```bash
git clone https://github.com/Verified-Intelligence/alpha-beta-CROWN
```

### 2. Create and activate the conda environment

```bash
conda env create -f environment.yml
conda activate assign4
```

### 3. Install alpha-beta-CROWN dependencies

Follow the installation instructions inside the cloned repo:

```bash
cd alpha-beta-CROWN
pip install -r requirements.txt
cd ..
```

---

## Running

### Step 1 — Train the model and export to ONNX

```bash
python train_model.py
```

This downloads MNIST, trains the MLP for 5 epochs, and writes
`models/mnist_mlp.onnx` (and `models/mnist_mlp.pth`).

### Step 2 — Run verification

```bash
export ABCROWN_PATH=alpha-beta-CROWN   # or set in the command
python test.py --abcrown-path alpha-beta-CROWN
```

Optional arguments:

| Argument | Default | Description |
|---|---|---|
| `--abcrown-path` | `$ABCROWN_PATH` | Path to cloned alpha-beta-CROWN repo |
| `--config` | `config.yaml` | YAML config file |
| `--eps` | (from config) | Override perturbation radius |
| `--n-samples` | 100 | Number of MNIST test images to verify |

### Run a single example manually

```bash
python alpha-beta-CROWN/complete_verifier/abcrown.py --config config.yaml
```

---

## Verification property

- **Model**: MNIST MLP (784 → 64 → 32 → 10, ReLU)
- **Dataset**: MNIST test set, samples 0–99
- **Property**: L∞-ball robustness with ε = 0.01
- **Timeout**: 60 s per sample
