# Assignment 4: alpha-beta-CROWN Neural Network Verification

Applies [alpha,beta-CROWN](https://github.com/Verified-Intelligence/alpha-beta-CROWN) to verify
L-inf robustness of a small MNIST MLP (784->64->32->10).
The same architecture used in Assignment 3 (Marabou) is reused to enable a direct comparison.

---

## Setup

### 1. Clone alpha-beta-CROWN

```bash
git clone https://github.com/Verified-Intelligence/alpha-beta-CROWN
git -C alpha-beta-CROWN submodule update --init --recursive
```

### 2. Create and activate the conda environment

```bash
conda env create -f environment.yml
conda activate assign4
```

### 3. Install alpha-beta-CROWN dependencies

```bash
pip install onnxoptimizer onnxsim sortedcontainers pyyaml psutil pandas appdirs coloredlogs
pip install "git+https://github.com/Verified-Intelligence/onnx2pytorch@8afb2243fddd1a4732883f1e2959f7e83f8201c5"
pip install -e alpha-beta-CROWN/auto_LiRPA
```

---

## Running

### Step 1 — Train the model and export to ONNX

```bash
python train_model.py
```

Downloads MNIST, trains the MLP for 5 epochs (~96% test accuracy), and writes
`models/mnist_mlp.onnx`.

### Step 2 — Explore the models directory (Problem 1)

```bash
python explore_resources.py --abcrown-path alpha-beta-CROWN
```

Prints a catalogue of all built-in models and YAML configurations, a comparison
with Marabou, and a list of installation issues encountered.

### Step 3 — Run verification (Problem 2)

```bash
python test.py --abcrown-path alpha-beta-CROWN
```

Runs alpha-beta-CROWN on 100 MNIST test samples with epsilon=0.01 (L-inf),
prints a side-by-side comparison with Marabou, and shows any adversarial examples found.

Optional arguments:

| Argument | Default | Description |
|---|---|---|
| `--abcrown-path` | `$ABCROWN_PATH` | Path to cloned alpha-beta-CROWN repo |
| `--config` | `config.yaml` | YAML config file |
| `--eps` | (from config) | Override perturbation radius |
| `--n-samples` | 100 | Number of MNIST test images to verify |

### Run abcrown directly

```bash
python alpha-beta-CROWN/complete_verifier/abcrown.py --config config.yaml
```

---

## Verification property

- **Model**: MNIST MLP (784 -> 64 -> 32 -> 10, ReLU), accuracy 96.31%
- **Dataset**: MNIST test set, samples 0-99
- **Property**: L-inf robustness with epsilon = 0.01
- **Timeout**: 60 s per sample

## Known installation issues

| # | Symptom | Fix |
|---|---|---|
| 1 | `AssertionError: Torch not compiled with CUDA enabled` | Add `general: device: cpu` to the YAML config |
| 2 | `RuntimeError: mat1 252x28 and mat2 784x64` (shape mismatch) | Include `nn.Flatten()` in the model; export ONNX with dummy input `(1,1,28,28)` |
| 3 | `ValueError: Config key ['bab','branching','reduce_op'] not found` | Correct key is `reduceop` (no underscore) |
| 4 | `UnicodeEncodeError` on Windows cp949 terminal | Add `sys.stdout.reconfigure(encoding='utf-8')` at top of script |
| 5 | `NotImplementedError` in `conda run` with multiline `-c` argument | Call `python.exe` directly instead of `conda run -n base python` |
